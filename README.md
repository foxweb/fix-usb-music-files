# Порядок треков на флешке для машины

Многие магнитолы не смотрят на номер в имени файла. Они играют то, что новее по дате. После обычного копирования все песни альбома получают почти одну и ту же дату, и альбом начинается не с первой песни.

Эта программа заново расставляет даты файлов на флешке:

- первая песня альбома получает самую новую дату;
- каждая следующая — на 2 секунды старше.

Магнитола, которая начинает с новых файлов, тогда играет альбом с начала. Содержимое песен остаётся прежним: меняются только дата создания и дата изменения.

Между песнями ровно 2 секунды, потому что на флешках (формат FAT32) время хранится с таким шагом. Если два альбома скопированы почти одновременно, их даты раздвигаются, чтобы альбомы не перемешались. Даты не сдвигаются в будущее.

## Что понадобится

- Компьютер Mac. На Windows программа не запустится: дату создания она записывает способом, который есть только в macOS.
- Флешка с музыкой.
- Программа «Терминал». Она уже стоит на Mac: Finder → «Программы» → «Утилиты» → «Терминал».

Python 3 тоже обычно уже есть. Проверка: откройте Терминал, вставьте строку ниже и нажмите Enter.

```bash
python3 --version
```

Если появится номер вроде `Python 3.12.0`, всё готово. Если компьютер напишет, что команда не найдена, установите Python 3 с сайта [python.org](https://www.python.org/downloads/).

Дополнительно ничего ставить не нужно.

## Как получить программу

1. На странице проекта на GitHub нажмите зелёную кнопку **Code**.
2. Выберите **Download ZIP**.
3. Распакуйте архив двойным щелчком.
4. Скопируйте файл `fix_track_dates.py` в корень флешки — туда, где лежат папки с альбомами.

Программа обрабатывает папку, в которой лежит этот файл, и все папки внутри неё.

## Как должны называться файлы

Номер песни стоит в начале имени:

- `01. Название.mp3`
- `01 - Название.mp3`
- `01_Название.mp3`
- `01 Название.mp3`
- `1-06 Название.flac` — это диск 1, песня 6

Папка, где меньше двух песен, пропускается. Файлы без номера уходят в конец альбома, по алфавиту, и в отчёте помечены `??`.

Подходят файлы: mp3, flac, m4a, aac, wav, ogg, wma, aiff, aif, ape, alac.

## Сначала только посмотреть

Первый запуск ничего не записывает. Он печатает план.

1. Вставьте флешку.
2. Откройте Терминал.
3. Наберите `python3` и пробел.
4. Перетащите файл `fix_track_dates.py` из окна Finder прямо в окно Терминала. Появится путь к файлу.
5. Нажмите Enter.

Если флешка в Finder называется `MUSIC`, та же команда выглядит так:

```bash
python3 /Volumes/MUSIC/fix_track_dates.py
```

Имя флешки у вас может быть другим. Его видно в боковой панели Finder. Перетаскивание файла надёжнее, чем набирать путь руками.

В списке у каждой песни две даты и знак между ними:

- `->` — дату планируется заменить;
- `==` — дата уже такая, как нужно.

Внизу будет сводка: сколько альбомов найдено, сколько файлов изменится, сколько файлов без номера.

## Записать даты

Когда список выглядит правильно, повторите запуск и в конце допишите ` --apply` (пробел перед двумя дефисами).

Через перетаскивание: `python3`, пробел, перетащите файл, пробел, `--apply`, Enter.

Или так, если флешка называется `MUSIC`:

```bash
python3 /Volumes/MUSIC/fix_track_dates.py --apply
```

Когда программа напишет «Даты записаны», флешку нужно извлечь штатно. В Finder нажмите кнопку извлечения рядом с флешкой и дождитесь, пока она исчезнет из боковой панели. После этого её можно вынимать.

## Если магнитола играет от старых к новым

Тогда первая песня должна быть самой старой. Сначала снова посмотрите план, уже с другим порядком:

```bash
python3 /Volumes/MUSIC/fix_track_dates.py --oldest-first
```

Если план верный, запишите его:

```bash
python3 /Volumes/MUSIC/fix_track_dates.py --oldest-first --apply
```

## Один альбом

Чтобы затронуть только папки, в пути которых есть нужные слова:

```bash
python3 /Volumes/MUSIC/fix_track_dates.py --album "Jazz"
```

Запись дат для этих папок — та же команда с `--apply` в конце. Остальные альбомы программа в этом запуске не меняет.
